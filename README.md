# Bakery Sales Analysis

## Project Overview
Analyzed more than 20,000 bakery transactions using Python and Pandas to evaluate sales performance, revenue, product demand, and time-based purchasing trends.

## Business Objective
Use transactional sales data to identify patterns in customer purchasing behavior, determine which products generate the greatest demand and revenue, and uncover trends that could support better business decisions.

## Tools & Techniques
- Python
- Pandas
- Jupyter Notebook
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Correlation Analysis

## Analysis
Explored bakery transaction data to evaluate product sales, revenue, and purchasing patterns. Analyzed relationships between sales variables and examined how customer demand changed across products and time periods.

## Key Findings
- Sales and revenue were concentrated among a smaller group of high-performing products.
- Product demand varied across different time periods.
- Weekend purchasing patterns differed from other periods.
- Transaction data revealed opportunities to better understand product demand and sales performance.

## Skills Demonstrated
- Cleaning and preparing transactional data with Python and Pandas
- Performing exploratory data analysis
- Analyzing sales and revenue trends
- Creating data visualizations
- Conducting correlation analysis
- Translating data into business insights
